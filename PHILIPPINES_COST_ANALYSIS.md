# Philippines Pricing: Cost Analysis & Minimum Viable Pricing

## 💸 **Cost Structure Analysis**

### **Per-User Monthly Costs**

#### **1. OpenAI API Costs**
```
Starter Tier (4 playbooks + 4 devotionals):
- 8 generations × 2,000 tokens avg × $0.002/1K tokens = $0.032/month
- Intelligence processing: ~$0.008/month
- Total OpenAI: ~$0.04/month ($0.48/year)

Growth Tier (15 playbooks + 15 devotionals):
- 30 generations × 2,000 tokens avg × $0.002/1K tokens = $0.12/month
- Intelligence processing: ~$0.03/month
- Total OpenAI: ~$0.15/month ($1.80/year)

Transformation Tier (Unlimited):
- Estimated 50 generations × 2,000 tokens = $0.20/month
- Intelligence processing: ~$0.05/month
- Total OpenAI: ~$0.25/month ($3.00/year)
```

#### **2. Database Costs (Supabase)**
```
Per 1,000 users:
- Database storage: ~$5/month
- API requests: ~$10/month
- Bandwidth: ~$5/month
- Total: $20/month ÷ 1,000 = $0.02/user/month
```

#### **3. Infrastructure Costs**
```
Per user/month:
- CDN & hosting: ~$0.01
- Monitoring & analytics: ~$0.005
- Backup & security: ~$0.005
- Total infrastructure: ~$0.02/user/month
```

#### **4. Payment Processing**
```
Philippines payment fees:
- Credit cards: 3.5% + ₱15
- GCash/PayMaya: 2.5% + ₱5
- Average: ~3% of revenue
```
